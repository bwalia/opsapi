HMRC sandbox test users

Make a fresh HMRC test taxpayer to try File My Tax end to end. Each one is a new person in HMRC's sandbox, not a real taxpayer.

Sandbox only. Copy the password now: it is shown once and is not stored here.
Using it in OpsAPI
  1. In File My Tax, add the National Insurance number shown.
  2. Choose File directly with HMRC and connect. On HMRC's page sign in with the User ID and Password, then grant access.
  3. OpsAPI finds (or, in the sandbox, sets up) the self-employment or UK property business and files against it.
